Distance-weighted Tversky index — implemented verbatim from the problem page and proven by tests.

Definition (official)

From the problem page: predictions p(x) ∈ [0, 1]; ground-truth set G; triangular kernel k(d) = max(1 − d/R, 0) with R = 300 m (3 px at 100 m):

TP_w = Σ_{g∈G}  max_{x: d(x,g)≤R}  p(x)·k(d(x,g))
FP_w = Σ_{x: p(x)>0}  p(x)·[1 − max_{g∈G} k(d(x,g))]
FN_w = Σ_{g∈G}  [1 − max_{x: d(x,g)≤R} p(x)·k(d(x,g))]
DTI  = TP_w / (TP_w + α·FP_w + β·FN_w + ε),  α = 0.2, β = 0.8

Identity (checked in tests): TP_w + FN_w = |G| for any prediction, giving the closed form DTI = TP_w / (0.2·(TP_w + FP_w) + 0.8·|G|).
