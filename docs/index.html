What this project is

The GEMS Prize asks for a pixel-wise probability map of geological faults across the GeoDAWN region of northwestern Nevada/eastern California — faults being the surface indicators of geothermal resources. Both prize rounds ($50K initial, $250K final) are scored against expert-labelled faults that are NOT in the public USGS database (rules PDF, verbatim quotes in Research). So this is a scientific discovery problem — find the unmapped faults — not a supervised segmentation problem.

  • Current target: beat the public-leaderboard leader 0.3049 DW-Tversky (our best so far: 0.1563, rank #23 of 50 — Results).
  • This repo's angle: metric-economics-first emission policies tuned on spatially-honest proxies + a blind detector that generalises the fault signature off-catalogue (Strategy).
  • Everything verifiable: sha256-pinned data, tests reproducing the official metric exactly, machine-written artifacts (Data, Metric).
