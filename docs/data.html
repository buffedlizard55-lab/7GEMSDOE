Download routes (no manual steps for the three rasters)

  1. Dropbox mirrors linked from the competition page — exact URLs in scripts/download_competition_data.sh; every file hash-checked after download.
  2. Git bridge fallback (used automatically when Dropbox is unreachable, as in this sandbox): sibling public repo buffedlizard55-lab/GEMSDOE data/bridge/ — 5 parts ≤ 100 MB, reassembled and hash-verified by scripts/assemble_data_bridge.py.
  3. DrivenData data tab — authoritative, login-walled (link). The only file not yet mirrored: 1m_DEM_links.csv.

Storage policy

Large rasters live in $GEMS_DATA_DIR (default ~/gems_data), outside git. Committed artifacts are small: test fixtures (~5 MB), the submission artifact (~3 MB), and JSON evidence. Any machine can rebuild the data placement with bash scripts/download_competition_data.sh and verify it with python scripts/verify_data.py.
